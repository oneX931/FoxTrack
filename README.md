# FoxTrack

Веб-приложение для учёта видеоигр. У каждого пользователя своя библиотека: игры ищутся в каталоге TheGamesDB, добавляются с нужными платформами, получают статус, оценку и отзыв.

## Возможности

- Регистрация и вход, сессии на httpOnly-cookie
- Поиск игр по каталогу TheGamesDB; издания и версии одной игры для разных платформ объединяются в одну карточку
- Библиотека с обложками, поиском по названию и фильтрами по статусу и платформе
- Статусы «Хочу пройти», «Играю» и «Пройдена»; для пройденных игр доступны оценка от 1 до 10 и отзыв
- Несколько платформ прохождения у одной игры
- Профиль: смена имени, почты и пароля, аватар
- Светлая и тёмная темы, интерфейс на русском и английском
- Адаптивная вёрстка, на телефоне есть нижняя навигация
- Защита API: Argon2id, ограничение частоты запросов, проверка Origin, заголовки Helmet

## Стек

Клиент:

- React 19 и React Router 8
- Vite 8
- Чистый CSS с дизайн-токенами, иконки lucide-react, шрифты Geist

Сервер:

- Node.js 24+ и Express 5
- SQLite через встроенный модуль `node:sqlite`
- Zod для валидации запросов
- Helmet, express-rate-limit, cookie-parser
- Хеширование паролей Argon2id из `node:crypto`

Внешний API: TheGamesDB.

## Запуск

Нужны Node.js 24 или новее и ключ API TheGamesDB.

```bash
npm install
cp server/.env.example server/.env
```

Ключ указывается в `server/.env` в переменной `TGDB_API_KEY`.

Режим разработки (клиент на порту 5173, API на порту 3001):

```bash
npm run dev
```

Сборка и запуск одним сервером на порту 3001:

```bash
npm run build
npm start
```
